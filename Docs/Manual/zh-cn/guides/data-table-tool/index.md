# DataTable 工具：从 CSV 生成可用数据表

DataTable 工具在 Godot 编辑器中维护 Schema、检查 CSV 并生成运行时表资源。它是内容生产流程的一部分，不在游戏运行时执行，也不应由业务代码直接修改生成物。

## 推荐流程

1. 为一类数据建立一个 Schema，并声明列、类型、键和 Client/Server 归属。
2. 在生成前先运行只读检查，修复列名、类型、引用和重复键问题。
3. 生成后将源 CSV、Schema 与生成物作为一个版本化变更复核。
4. 在运行时通过 `DataTableService` 加载已生成的数据，不读取 CSV。

## 关键规则

- 生成失败不应留下被当作有效数据使用的半成品。
- CSV 是内容源，生成表是受工具管理的产物；不要手工修改产物绕过检查。
- 导出前确认生成物没有过期，并验证 Client/Server 隔离。

工具操作、生成验证和运行时读取见[DataTable 工作流](../data-tables/index.md)。
