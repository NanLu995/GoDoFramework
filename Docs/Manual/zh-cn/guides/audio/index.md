# Audio：管理 BGM、音效与播放预算

`AudioService` 用于长期 BGM 和短音效。游戏流程决定何时切换 BGM，业务交互按优先级和容量请求音效；不要让任意节点各自创建播放器或管理全局音量。

## 使用建议

- BGM：由 Procedure 或明确的场景协调边界切换，处理淡入淡出、暂停和场景退出。
- 2D/3D SFX：仅在玩家操作、命中等低频事件请求播放，并检查结构化播放结果。
- 音量：通过 Audio Bus 与 Settings 协作持久化，不把音量逻辑复制到每个播放点。

## 关键规则

- 音效容量、同资源限制和抢占优先级是可观察的播放策略，不应静默假设“每次都一定播放”。
- 3D 音效的跟随、物理帧更新和距离衰减有独立预算；静态坐标与跟随 Node 的选择会影响生命周期。
- 音频 API 必须从 Godot 主线程调用，不能把播放器控制放到后台任务。

具体 BGM、音效、设置与退出清理见[UI 与 Audio 工作流](../ui-and-audio/index.md)。
